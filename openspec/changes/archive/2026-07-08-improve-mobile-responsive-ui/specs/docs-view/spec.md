## ADDED Requirements

### Requirement: Tab dokumentasi adaptif di mobile

Tab pemilihan bagian dokumentasi (Arsip Surat / Media Event / Branding Kit) SHALL muat dan dapat dipilih pada layar mobile tanpa mengharuskan pengguna menggeser ke samping untuk menjangkau opsi lain.

#### Scenario: Memilih tab di mobile

- **WHEN** pengguna membuka halaman dokumentasi pada viewport mobile
- **THEN** ketiga tab terlihat dan dapat langsung dipilih tanpa perlu menggeser (scroll horizontal) area tab

### Requirement: Tabel arsip surat menampilkan data dan aksi di mobile

Tampilan mobile tabel arsip surat SHALL menampilkan data yang memadai beserta aksi baris yang relevan.

#### Scenario: Arsip surat pada layar mobile

- **WHEN** pengguna melihat tab Arsip Surat pada viewport mobile
- **THEN** informasi penting tiap surat tetap terbaca dan aksi (mis. buka/lihat) tersedia, tidak hilang seperti sebelumnya
