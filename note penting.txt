hai Z... saya punya Projek web HMTI nih, sudah 25% proses pengerjaan... konsep nya tuh web ini dibagi menjadi 2 fungsi utama... fungsi publikasi, di mana isi nya seperti showchase profil himpunan (Himpunan Mahasiswa Teknik Informatika), biodata anggota (foto keren dengan halaman interaktif), kegiatan, event, prestasi perorangan maupun himpunan itu sendiri, dll... fungsi kedua sebagai sarana pengelolaan data Himpunan itu sendiri... seperti Anggota (ini sudah hampir jadi), keuangan, dokumentasi baik surat menyurat, desain, foto2, video2, dll... 

teknologi yang digunakan :
Frontend: Vue 3 (Composition API) + Tailwind CSS + Axios.

Backend: NestJS (TypeScript).

Database: SQLite dengan Prisma ORM.
